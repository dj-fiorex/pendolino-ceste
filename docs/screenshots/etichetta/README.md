# Etichette — reference screenshots

Variant B of the #31 prototype ("Foglio e impostazioni"), chosen on
2026-08-26: the Etichette PDF of #29 as the tipografia will see it — the
range just entered, one label per page — with the Admin settings beside
it, plus the label itself as ADR-0007 describes it. Fake data; the mill's
name and phone are placeholders. Label size assumed 100 × 150 mm. Taken at
390 × 844 (telefono) and 1180 × 820 (tablet), light theme.
